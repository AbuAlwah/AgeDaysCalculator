A clean, modern, and precise desktop application built with **C# WinForms** and **Guna UI2**. This application features exact age calculation (years, months, days), a live countdown to the next birthday, and comprehensive lifetime statistics (total days and total hours lived)—all presented in a sleek, dark-themed UI.

## ✨ Features

- **Exact Age Calculation:** Accurately calculates exact age in **Years**, **Months**, and **Days** .
- **Next Birthday Countdown:** Automatically computes the remaining days until the upcoming birthday.
- **Lifetime Statistics:** Real-time tracking of total days and total hours lived, formatted with clean, readable number separators.
- **Smart Date Validation:** Built-in safeguards that prevent future date selections and ensure data accuracy.
- **Modern Dark UI/UX:** Built with Guna UI2 components for rounded corners, custom controls, crisp typography, and an intuitive layout.
- **Quick Reset:** One-click clear functionality to instantly reset all inputs and statistical indicators.
